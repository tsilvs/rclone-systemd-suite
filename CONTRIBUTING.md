# Contributing

## Issues

Report bugs, request features via [GitHub Issues](../../issues).

## Pull Requests

1. Fork repo
2. Create feature branch
3. Test changes locally (user + system install)
4. Submit PR with clear description

## Code Style

- POSIX sh compatible
- Tabs for indentation
- Keep it simple, minimal dependencies
